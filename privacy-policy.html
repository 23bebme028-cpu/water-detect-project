JalSaarthi AI — Privacy Notice

This SIH prototype is a demonstration application. In its GitHub Pages configuration, request records are stored locally in the user's browser using IndexedDB. They are not transmitted to a server by the prototype.

Data minimisation

Do not enter Aadhaar numbers, passwords, financial information, medical records or other unnecessary sensitive information into this demo.

Production deployment

A production version must use authenticated APIs, HTTPS, server-side authorization, database row-level security, encrypted storage, audit logging, defined retention/deletion policies and an approved government data-processing environment.

Evidence

The prototype stores only the evidence filename as a local record. It does not upload the selected image.

Deletion

The application provides a Clear local data control that deletes the prototype records stored in this browser.
