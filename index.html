Privacy & Data Protection

Data minimisation

Collect only the information needed to process a request. Avoid Aadhaar numbers, passwords and unnecessary personal identifiers.

Local-first prototype

The GitHub Pages demo stores request records in IndexedDB on the user's device. No API or cloud upload is configured.

Production protection

For deployment with real citizens, use authenticated access, HTTPS, server-side authorization, database row-level security, audit logs, retention rules and encrypted storage.

Consent & deletion

Tell users what is collected, why it is needed and how long it is retained. Provide deletion/export controls where appropriate.
